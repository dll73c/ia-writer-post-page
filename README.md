# ia-writer-post-page

This repository hosts public files meant to be embedded in other pages, such as images, badges, and other assets that need to be referenced via a direct URL.

To use an asset, copy the file path and reference it in an HTML page:

```html
<img src="https://dll73c.github.io/ia-writer-post-page/assets/FILE.png" alt="Description">
```

Files must be versioned and kept with stable names, since the URLs are consumed externally.
